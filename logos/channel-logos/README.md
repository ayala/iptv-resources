# Channel logos

This directory contains normalized channel logos intended for automated IPTV
channel matching.

## Filename convention

```text
<normalized-channel-name>-<country-code>.<extension>
```

Examples:

- `cnn-us.png`
- `fox-news-channel-us.png`
- `hbo-xtreme-mx.png`

Names are lowercase and generally use hyphens in place of spaces. The final
two-letter suffix identifies the channel market and should be retained by
consumers when selecting candidates for a country-specific lineup.
